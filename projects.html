My Projects

Here are some of the projects I've worked on:

My first project was creating a three-page website. I enjoyed working on it because I built it using only table, tr, and td elements, without using div yet. It was a clone of a Realme website, which helped me practice structuring layouts in a simple but effective way

For my second project, we worked as a group to create a movie website inspired by Netflix, which required building 25 pages. One of the main challenges I encountered was the site being flagged as a dangerous website, but I was able to find a solution and overcome the problem.

For my third project, we worked as a group to develop a café system using C#. It was quite challenging, especially because of the programming language and handling the database. The system was designed to be used by employees, managers, and administrators, making it more complex but also more practical and realistic.
